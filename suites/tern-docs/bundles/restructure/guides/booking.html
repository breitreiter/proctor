Booking and tracking parcels

Book a parcel with POST /v2/shipments, then follow it with GET /v2/shipments/{id}. Every field is in the Shipments reference.

Retrying safely

Send an Idempotency-Key header with a value unique to the booking, such as your order reference. If the connection drops before you see the answer, send the same request with the same key: Tern returns the shipment it already booked rather than booking another. Without the header, every request books a new parcel.

Following a parcel

A parcel's status moves from booked to delivered; the Statuses page says what each step means.
