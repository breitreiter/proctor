Quickstart for Python

Base URL and key

Production is https://api.tern.example. Your sandbox is at the URL in your dashboard; test keys start with tern_test_. Send the key as a bearer token on every request.

Your first quote

import os
import requests

response = requests.post(
    os.environ["TERN_API_URL"] + "/v1/quotes",
    headers={"Authorization": "Bearer " + os.environ["TERN_API_KEY"]},
    json={"from_postcode": "EH6 6QT", "to_postcode": "M1 1AE", "weight": 1.2},
)
for quote in response.json()["quotes"]:
    print(quote["service"], quote["amount"], quote["eta_days"])

Each quote has a service, an amount and the days to deliver. Next: the booking guide.
