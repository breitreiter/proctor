Shipments

POST /v2/shipments

Book a parcel. Fields: service, from_postcode, to_postcode, weight (grams) and reference, your own reference for the order. The response is the shipment, status booked, with its id.

Retrying safely

Send an Idempotency-Key header with a value unique to the booking, such as your order reference. If the connection drops before you see the answer, send the same request with the same key: Tern returns the shipment it already booked rather than booking another. Without the header, every request books a new parcel.

Idempotency-Key: order-LT-5123

GET /v2/shipments

Your shipments, oldest first, twenty to a page. Parameters:

created_sinceA date, YYYY-MM-DD: only shipments created on or after it.
cursorThe next_cursor from the previous page.

The response holds shipments and next_cursor, which is null on the last page. Keep the same created_since when you follow a cursor.

GET /v2/shipments/{id}

One shipment: id, reference, service, status (see Statuses) and created_at.

POST /v2/shipments/{id}/cancel

Cancel a shipment that has not been collected. The response is the shipment, status cancelled. Once the parcel is collected it can no longer be cancelled: the answer is 409 with "error": "conflict".
